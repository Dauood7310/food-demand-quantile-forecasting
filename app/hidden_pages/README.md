# Hidden pages

These three pages are not shown in the side menu of the app:

- `3_Accuracy_results.py` - which model forecasts best (question 1)
- `4_Quantile_results.py` - forecasting a safe amount (question 2)
- `5_Cost_results.py` - waste, missed orders and cost (question 3)

To show a page again, move its file back into the `app/pages` folder and restart the app.
